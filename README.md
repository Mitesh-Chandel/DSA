# Data Structures and Algorithms in Java

A curated collection of Java solutions to common data structures and algorithms problems, organized by topic.

## How this repo is organized

Each topic has its own folder, and each solution is a standalone Java class with problem metadata, an approach, complexity, and a `main` method for quick testing. Use [`templates/Solution.java`](templates/Solution.java) as a starting point. Run `python update_readme.py` to refresh this overview from solution headers.

## How to add a new solution

1. Copy [`templates/Solution.java`](templates/Solution.java) into the appropriate topic folder and give the class and file a descriptive name.
2. Complete the metadata header, solution method, and test cases in `main`.
3. Run `python update_readme.py` to update the progress counts and topic tables.
